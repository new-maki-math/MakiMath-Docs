# 导入与导出

如果只是想把自己写的讲义带到另一台电脑，使用整本讲义 JSON。如果已经有多篇 Typst 文件，想把它们放进某个章节，使用小节导入。两种操作解决的问题不同，不需要先了解文件内部的数据结构。

## 保存一份可以继续编辑的讲义

在讲义工作台打开要导出的讲义。在线讲义还要确认选中的是哪一个版本，然后先保存全部修改，再点击“导出 JSON”。

导出的文件包含这一个版本的讲义信息、目录、小节源码、渲染配置和封面。以后可以重新导入并继续编辑，因此它适合备份和转移内容。

它不包含账号、协作者、审核记录、全部历史版本或读者的掌握记录。导出一本在线讲义，不等于备份了这本讲义在平台上的所有历史。

本地讲义只保存在当前浏览器里。更换设备、清除站点数据之前，先把 JSON 下载到你能找到的位置；重要讲义也可以按日期保留几份文件，不要把唯一一份备份仍放在浏览器中。

## 导入为一本新讲义

在工作台的本地或在线讲义分组使用“导入 JSON”，选择从平台导出的文件。读取成功后，核对讲义名称、目录数量和课程标识，再确认导入。

导入会新建一本讲义，不会覆盖同名讲义。出现标识重复提示时，更换一个未使用的标识，例如在原标识后加上 `-notes`。只修改显示名称，不能解决标识冲突。

不登录时可以导入本地讲义；有在线创作权限时，可以导入为在线工作草稿。导入不会直接公开发布，也不会继承原作者的权限或审核结果。讲义分类需要在导入后重新选择。

如果网络中断，提示无法确认导入结果，先刷新列表检查是否已经创建，不要连续点击确认，以免新建多份。

## 把多个 Typst 文件放进一个章节

在工作台选中一个可编辑的章节，找到“批量导入小节”，选择一个或多个 `.typ` 文件。每个文件会变成一个小节，文件名先用作小节标题，并尝试生成标识。

确认前检查标题、标识和内容顺序。中文文件名不一定能生成有效标识，需要手动填写；同一批文件的标识也不能与章内已有小节重复。文件应使用 UTF-8 编码，平台不会把 PDF、Word 或 LaTeX 文件自动转换成 Typst。

确认导入后，这些小节会追加到当前章节，原有小节保留。随后还需要保存讲义，这一步才会把目录和正文写入本地或服务器。

一个文件对应一个小节，不会因为文件里写了多个标题就自动拆节。想分别阅读和排序的内容，可以先拆成多个文件再导入。读取过程中切换章节会取消这次选择，需要在目标章节重新操作。

## JSON、Typst 文件和 PDF 怎么选？

| 你想做什么 | 使用什么 |
| --- | --- |
| 备份整本讲义，换设备后继续编辑 | 导出 JSON |
| 将已有正文批量加入某个章节 | 导入 `.typ` 小节 |
| 给别人阅读，或打印成纸质讲义 | 打印讲义，另存为 PDF |

PDF 是已经排好的阅读结果，不能通过“导入 JSON”重新变回工作台目录。需要保留可编辑版本时，导出 JSON；需要固定当前阅读内容时，再保存一份 PDF。

打印入口位于课程讲义详情页。选择需要的范围和深浅色后，先“准备打印”，准备完成再打开浏览器打印窗口，选择打印机或“另存为 PDF”。深色打印可能需要在浏览器设置中开启“背景图形”。

## 引用和封面也会一起保存吗？

封面会随整本 JSON 保存。在线封面最多 512 KiB，本地封面最多 5 MiB；较大的本地封面准备导入线上时，需要先缩小。

知识点引用只保存 `#mm-knowledge(slug: "...")` 这条代码，不包含对应知识点正文。接入平台后可以继续读取公共内容，但单凭这个 JSON 文件，不能保证断网时仍能展开所有引用。掌握记录也不会随讲义 JSON 转移。

如果导入失败，先确认文件是不是讲义工作台导出的 JSON，或当前入口要求的 `.typ` 文件。用于知识库导入的 JSON 与讲义 JSON 不是同一种格式，不能混用。源码过长、标识不合法或封面超限时，按提示处理后再导入；单节源码上限为 200000 字符，整本在线导入还受请求总大小限制。

讲义归档期间不能导出。需要继续整理时，先按已有权限恢复归档；也不要在讲义正文或渲染配置中保存账号密码等私密信息，它们可能随着文件一起发出去。
