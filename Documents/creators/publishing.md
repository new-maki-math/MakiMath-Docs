# 发布我的讲义

你可以先写，再考虑发布。本地讲义不要求注册，内容完成后也可以通过 JSON 转移到在线创作，不必为了等待账号开放而推迟整理。

## 先获得在线创作权限

公开发布需要注册、登录，并具备在线创作权限。目前注册使用邀请码，但邀请码如何申请、面向哪些用户开放，还在商讨中，确定后会在这里说明。

暂时没有邀请码时，先在工作台编写本地讲义，并及时导出 JSON 备份。不要把“暂时不能在线发布”理解成“不能使用平台创作”。

## 把讲义准备好

已有在线创作权限后，可以新建在线讲义，也可以把本地导出的 JSON 导入为在线工作草稿。导入不会直接公开，课程标识也需要与服务器上已有的讲义区分。

提交之前，按读者的方式浏览一次：讲义名称和简介能不能说明内容，目录顺序是否清楚，公式是否正常，引用是否能加载，例题条件和来源是否写明。预览里仍有错误或缺失引用时，先处理再提交。

如果知识点已经由公共知识库提供，尽量使用引用，把自己的理解、例子和过渡说明放在前后。这样读者换一份讲义时，仍然能辨认相同的知识点并共用掌握记录。

## 提交审核

先保存全部修改，再点击“提交审核”。在确认窗口核对预计版本和快照说明，等待倒计时结束后确认。提交成功后，会得到一份只读审核快照，原草稿仍然可以继续编辑。

管理员审核的是这份快照。提交后才写进草稿的内容，不会自动加入本次审核。需要了解版本关系时，可以看[保存、版本与审核](./versions-review.md)。

如果被驳回，根据审核意见调整草稿，保存后重新提交。审核没有固定的完成时长；有待审核快照时，先等待这次处理结果。

## 公开与推荐

审核通过后，这份快照可以公开阅读，讲义的公开入口会指向它。之后修改工作草稿，不会立即改变读者看到的内容；新修改还需要再次保存、提交和审核。

公开发布不等于获得平台推荐。推荐由管理员单独设置，不应把是否出现在推荐位置当成审核是否成功的判断标准。

读者可以把公开讲义添加到自己的书架，下载为本地副本。之后他们的修改只影响自己的副本，不会改动你的在线原件；你发布新版本，也不会自动覆盖他们已经下载的内容。

目前尚未公布统一的邀请码申请和创作者准入办法。本页说明的是已有创作权限后的发布流程，开放安排请以后续公告为准。
