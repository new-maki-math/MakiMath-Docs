# 使用MM教学宏

讲义里经常需要把定义、定理、例题和提醒单独标出来。MM 教学宏就是这些现成的排版工具：你负责写内容，平台负责显示标题、边框和配色，不需要每次自己拼样式。

宏名称前面的 `#` 不能省略。最简单的写法是：

```typst
#mm-box-warn[
  使用这个结论前，先检查函数在区间上是否连续。
]
```

## 选择合适的教学框

按内容的用途选择框，不必每一段都包起来。普通讲解直接写正文，只有需要读者辨认性质的内容，再使用对应的框。

| 宏 | 适合放什么 |
| --- | --- |
| `#mm-box-definition[...]` | 定义、概念的准确表述 |
| `#mm-box-theorem[...]` | 定理、性质和公式 |
| `#mm-box-example[...]` | 例题及其讲解 |
| `#mm-box-warn[...]` | 提醒、易错点、适用范围 |
| `#mm-box-conclusion[...]` | 结论、推论和需要归纳记住的内容 |
| `#mm-box-frequency[...]` | 真题考频及相关说明 |
| `#mm-box-homework[...]` | 作业和练习安排 |
| `#mm-box-custom[...]` | 不属于以上类型的自定义内容 |

前七种框会显示自己的类型标题。想补充名称，可以传入 `title`：

```typst
#mm-box-theorem(title: [等比数列求和])[
  当 $q != 1$ 时，前 $n$ 项和为

  $ S_n = frac(a_1 (1-q^n), 1-q) $
]
```

`title: [...]` 中的方括号表示一段内容，不要改成 `title: "..."`。标题可以包含简短文字、行内公式或标签，表格、大段证明和其他教学框放到正文里。

教学框目前只接受可选的 `title` 参数和一个正文内容块，不能另外传 `color` 改变整个框的配色。固定类型已经有对应的样式，会随网站深浅色主题调整。

## 普通说明也可以有自己的标题

不想使用“定义”“定理”这类固定标题时，用自定义框：

```typst
#mm-box-custom(title: [为什么先学这一节])[
  后面讨论函数极限时，会反复用到这里的数列例子。
  先熟悉这些例子，再看一般定义会更容易。
]
```

`mm-box-custom` 不会额外加上“自定义”三个字。省略标题或使用空标题时，通常不显示标题栏，适合只需要集中放置一段内容的情况。

## 添加简短标签

标签适合“重点”“仅数一”“选读”等短文字，不适合包住整段解释。

```typst
#mm-tag(color: "blue")[重点]
#mm-tag(color: "rose")[仅数一]
#mm-tag(color: "green")[选读]
```

预设颜色有 `blue`、`cyan`、`green`、`orange`、`rose`、`purple` 六种。省略 `color` 时默认蓝色，使用预设通常就够了。

标签也可以放进标题：

```typst
#mm-box-example(title: [一道基础题 #mm-tag(color: "green")[入门]])[
  求 $lim_(n -> infinity) frac(1, n)$。
]
```

确实需要自定义颜色时，可以使用静态 RGB 值，例如 `#mm-tag(color: rgb("B22234"))[补充]`。自定义颜色需要自己检查深浅色下是否清楚，不支持的颜色会给出提示并回退到默认色。

## 编排一道题目

只需要展示一道例题和讲解时，`mm-box-example` 就够了。需要另外记录来源、题目标识或难度时，可以使用 `mm-question`：

```typst
#mm-question(
  source: "自编练习",
  title: [判断数列的变化],
  difficulty: 2,
  id: "sequence-01"
)[
  对数列 $a_n = frac(1, n)$，选择正确的结论。

  #mm-question-options(
    columns: 2,
    [每一项都大于零],
    [每一项都小于零],
    [从某一项开始恒为零],
    [没有极限]
  )
]
```

`source` 是来源说明，`title` 是补充标题，`difficulty` 是 1 到 5 的整数，`id` 是作者为题目填写的字符串标识。这些参数都可以省略；不确定难度时，直接不填，不需要为了使用题目框给出一个评分。

每个选项写在独立的 `[...]` 中，平台会显示 A、B、C 等编号。`columns` 可以填 1、2、4，也可以省略。选项较长时建议先用一列，窄屏显示时列数也可能减少。

填空位置可以这样写：

```typst
#mm-question(title: [求极限])[
  数列 $a_n = frac(1, n)$ 的极限为 #mm-question-blank(width: 6em)。
]
```

`mm-question-blank` 不带正文内容块，`width` 可以省略，默认宽度为 `4em`。这里的空白只是排版，不是供读者填写并提交答案的输入框。题目、选项和填空目前不提供自动评分或答题记录。

## 什么时候应该引用知识库？

直接写一个定理框，只是在当前小节里新增了普通内容，并不会自动成为知识库条目，也不会自动拥有跨讲义的掌握记录。

如果要使用的定义、定理或公式已经在知识库中，优先[引用知识库](./knowledge-references.md)。引用会渲染知识点本身的教学框，你只需要在前后写自己的说明，不必再套一层相同的框。

不建议为了让每段看起来整齐而全部使用教学框。框越多，真正需要强调的内容反而越难找到。旧讲义中的 `defbox`、`thmbox`、`zt` 等名称也不能直接代替 MM 宏，应按这里的写法调整。
