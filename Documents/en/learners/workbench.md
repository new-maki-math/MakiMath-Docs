# Lecture Workbench

The lecture workbench is where you organize and create content. You can write your own study notes or arrange an entire course into a lecture.

## Choose your teaching order

A lecture consists of chapters and sections. You can rearrange them, add titles and summaries, and write Typst content in each section.

The knowledge library provides shared knowledge, while lectures preserve each author's arrangement. Creators decide what to introduce first, which examples to use and how to explain difficult points.

## Write content and reference knowledge

A preview beside the editor helps you check text, formulas, tables and teaching boxes. You can write content directly or search for and insert knowledge point references, then add explanations, proof ideas or exercises around them.

A successful preview does not mean your work has been saved. Save after editing. If you leave unsaved content, the page asks you to confirm.

## Local and online authoring

Local lectures do not require signing in and are stored in your browser. They suit personal notes and can be exported as JSON to keep a copy, then imported on another device.

Online authoring requires signing in with the appropriate permissions. Saving updates only the working draft. Submitting for review creates an independent snapshot from the saved content. Further edits to the draft do not change the submitted snapshot. The public reading version updates only after an administrator approves it.

The workbench also provides JSON import and export for entire lectures and batch import of .typ files as sections within a chapter, helping you move and organize existing content.
