# How do I publish my lecture?

To publish a lecture publicly, you need to register, sign in and have online authoring permission before submitting it for review. Registration currently requires an invitation code. How to apply for a code and who will be eligible are still being discussed. Details will be added here once decided.

You can start writing a local lecture in the lecture workbench without waiting for registration to open. Content is stored in your current browser, so export JSON backups promptly. Once you have online authoring permission, you can import it as an online lecture.

When you finish editing an online lecture, save it before submitting it for review. Submission creates a review snapshot from the saved content. You can continue editing the draft, but those changes will not be included in the snapshot already submitted.

Once an administrator approves the lecture, it can be read publicly. Public publication and platform recommendations are separate: approval does not guarantee inclusion in the recommended list.

If you cannot register yet, keep your local lectures backed up. The invitation code application process has not been finalized; please refer to future announcements.
