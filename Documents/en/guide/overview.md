# Project overview

MakiMath separates public knowledge and authored lectures. Administrators maintain stable knowledge IDs with current source, categories and prerequisites. Lectures organize full source by chapter/section, referencing knowledge slugs.

The library supports relation browsing and local mastery. The workbench separates online content and browser copies. Online submission makes an independent review snapshot; approval publishes and recommendation is separate. Knowledge references resolve current content, so snapshots do not freeze knowledge bodies.

Frontend rendering maps a supported Typst/MM subset to web components; the backend stores source and enforces authorization/version workflows. Local lectures, mastery and log read state have no cross-device synchronization.
