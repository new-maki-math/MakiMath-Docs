# Publishing My Lecture

You can write first and think about publication later. Local lectures do not require registration. Once ready, you can move them to online authoring via JSON; there is no need to postpone organizing your material while waiting for an account.

## Get online authoring permission

Public publication requires registering, signing in and having online authoring permission. Registration currently uses invitation codes, but how to apply and who will be eligible are still being discussed. Details will be added here once decided.

Without a code, write a local lecture in the workbench and export JSON backups regularly. Being unable to publish online for now does not stop you from creating on the platform.

## Prepare your lecture

With online authoring permission, create an online lecture or import an exported local JSON as an online working draft. Import does not publish it directly, and the course identifier must be distinct from those already on the server.

Before submitting, review it as a reader would: do the title and summary describe the content, is the outline clear, do formulas display, do references load, and are example conditions and sources stated? Resolve preview errors or missing references before submitting.

If the public knowledge library already provides a knowledge point, consider referencing it and adding your understanding, examples and transitions around it. Readers can then recognize the same point and share mastery records across lectures.

## Submit for review

Save all changes, then click “Submit for review”. Check the expected version and snapshot description in the confirmation window, then confirm after the countdown. A successful submission creates a read-only review snapshot; you can continue editing the original draft.

Administrators review that snapshot. Content added to the draft after submission does not automatically enter the current review. See [Saving, Versions & Review](./versions-review.md) for how the versions relate.

If rejected, adjust the draft based on the review feedback, save and submit again. There is no fixed review completion time. If a snapshot is already pending, wait for that review's result.

## Publication and recommendation

After approval, the snapshot can be read publicly and the lecture's public entry points to it. Later changes to the working draft do not immediately change what readers see; new changes need to be saved, submitted and reviewed again.

Public publication does not guarantee a platform recommendation. Administrators set recommendations separately, so a lecture's presence in a recommended location is not a reliable test of approval.

Readers can add a public lecture to their bookshelf and download a local copy. Their later changes affect only their copy, not your online original. Publishing a new version does not automatically overwrite copies they already downloaded.

A common invitation application and creator admission process has not yet been announced. This page describes publishing once you have authoring permission; consult future announcements for availability.
