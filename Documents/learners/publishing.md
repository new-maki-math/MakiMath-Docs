# 如何发布我的讲义？

公开发布讲义需要先注册并登录，具备在线创作权限后，才能将讲义提交审核。目前注册需要邀请码，邀请码如何申请、面向哪些用户开放，还在商讨中，确定后会在这里说明。

你可以先在讲义工作台编写本地讲义，不需要等待账号开放。内容保存在当前浏览器中，建议及时导出 JSON 备份；之后获得在线创作权限，可以再导入为在线讲义。

在线讲义编辑完成后，先保存，再提交审核。提交时，平台会根据已经保存的内容创建一份审核快照。你仍然可以继续修改草稿，但这些修改不会进入已经提交的快照。

管理员审核通过后，这份讲义就可以公开阅读。公开发布与平台推荐是两件事：审核通过不代表一定会进入推荐列表。

如果暂时无法注册，先保留好本地讲义即可。目前还没有确定的邀请码申请流程，请以后续公告为准。
