# 讲义工作台

讲义工作台是整理和创作内容的地方。你可以写自己的学习笔记，也可以把一门课组织成完整讲义。

## 安排自己的讲解顺序

一本讲义由章节和小节组成。你可以调整它们的顺序，填写标题和简介，并在每个小节中编写 Typst 正文。

知识库提供共同的知识内容，讲义则保留作者自己的安排。先介绍什么、用什么例子、怎样解释难点，都由创作者决定。

## 编写正文与引用知识

编辑器旁边提供预览，方便核对文字、公式、表格和教学框。你可以直接书写内容，也可以搜索并插入知识点引用，再围绕它补充解释、证明思路或练习。

预览显示成功不等于已经保存。编辑完成后需要保存，离开未保存的内容时，页面会提醒你确认。

## 本地创作与在线创作

本地讲义不需要登录，内容保存在当前浏览器中。它适合个人整理，也可以通过 JSON 导出保存，再导入到其他设备。

在线创作需要登录并具备相应权限。保存只更新工作草稿；提交审核时，会根据已保存内容创建一份独立快照。之后继续修改草稿，不会改变已经提交的快照。管理员审核通过后，公开阅读入口才会更新。

工作台也提供整本讲义 JSON 导入导出和章节内批量导入 .typ 小节的入口，方便搬运与整理已有内容。
