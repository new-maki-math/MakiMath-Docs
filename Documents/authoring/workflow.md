# 讲义编排规范与 DAG 图谱

MakiMath 的核心特性在于将数学知识从“传统线性书卷”重构为“立体有向图谱”。本篇文档详细说明平台的讲义数据组织规范以及前置依赖网络的设计机制。

## 四级层级模型

平台将所有讲义与课程内容划分为四个严格的树状层级：

![四级层级模型](/images/content-hierarchy.svg)

### 1. 分类 (Category)
- **定义**：学科大类或专业方向，例如：`高等数学`、`线性代数`、`概率论与数理统计`。
- **属性**：
  - `name`：分类中文名称。
  - `slug`：URL 友好标识（仅限小写英文字母、数字和连字符，如 `advanced-calculus`）。
  - `pos`：全平台展示排序。

### 2. 课程 (Course)
- **定义**：某一门完整的知识课程或专题讲义，例如：`高等数学强化精讲`、`考研线性代数导引`。
- **属性**：
  - `title`：课程全称。
  - `subtitle` / `descr`：副标题与课程简介。
  - `status`：发布生命周期（`draft` 草稿、`live` 公开、`hidden` 隐藏、`archived` 归档）。
  - `prereqs`：前置课程 ID 数组，用于规划宏观专业培养路径。

### 3. 章节 (Chapter)
- **定义**：课程下的主题大章，例如：`第一章 极限与连续`、`第二章 导数与微分`。
- **属性**：
  - `tag`：章节序号标识（如 `第 1 章`、`Chapter 1`）。
  - `title`：大章名称。
  - `summary`：章节导读与核心考点综述。
  - `pos`：在课程内的排序权重。

### 4. 小节 (Section)
- **定义**：讲义的最小实体承载单元，真正存放 Typst 源码与数学定理的地方，例如：`1.1 等价无穷小代换`。
- **属性**：
  - `tag`：小节序号（如 `1.1`）。
  - `title`：小节标题。
  - `source`：Typst 讲义源码。
  - `source_hash`：源码的 SHA-256 哈希值，用于协商缓存与并发保存防覆盖。
  - `prereqs`：前置小节 ID 数组。

## DAG 前置依赖网络

在数学学科中，知识掌握具有严格的先后逻辑。MakiMath 允许小节之间建立显式的依赖关系，构成有向无环图（Directed Acyclic Graph, DAG）。

![DAG 前置依赖网络](/images/dag-workflow.svg)

### 1. 小节依赖原则
- **最小前置集**：仅勾选掌握当前小节所**必需**的前提节点，无需跨层级重复勾选传递性前置（例如已依赖 B 且 B 依赖 A，则无需在当前节点重复勾选 A）。
- **防自环与防成环**：
  - 数据库级别强制约束：`CONSTRAINT sections_no_self_prereq CHECK (NOT (id = ANY (prereqs)))`。
  - 编者在配置依赖时，系统会自动进行拓扑回路检测，杜绝死循环引用。

### 2. 依赖上卷机制 (Rollup Edges)
在宏观课程概览页中，若直接绘制数百个小节的依赖关系，界面会过于繁杂。平台采用智能**依赖上卷算法**：

$$Section(p) \in prereqs(Section(s)) \implies Chapter(p) \xrightarrow{Edge} Chapter(s)$$

- 同一章节内部的小节依赖只在阅读页与小节清单中体现。
- 跨章节的小节依赖会自动聚合为**大章之间的宏观学习路线边**，由 D3 渲染引擎绘制出清晰的章节知识图谱。

## 编排最佳实践

1. **粒度控制**：单个小节阅读时长建议控制在 5~15 分钟以内，包含 1~2 个核心概念/定理及 2~3 道经典例题。
2. **Slug 命名规范**：保持简短且语义明确，建议格式为 `ch01-limits-intro`，利于 SEO 与外链引用。
3. **前置说明文案**：系统会根据所选前置节点自动生成读者提示语（如：“学完 柯西中值定理 后可学”），确保学习者心中有数。
