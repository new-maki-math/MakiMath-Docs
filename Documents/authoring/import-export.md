# 讲义 JSON 与小节导入

整本讲义 JSON 用于交换**一个确定版本**的内容，不是数据库备份，也不是把所有版本打包。在线与本地使用相同的maki-lecture/schema_version=1格式。本轮只静态核对代码，未运行导入导出验证。

## 完整格式

下列字段全部必填，未知字段会被拒绝。无内容的可空文案仍须传空串，metadata须为对象。

```json
{
  "type": "maki-lecture",
  "schema_version": 1,
  "lecture": {
    "slug": "limits-intro", "title": "极限入门", "subtitle": "",
    "summary": "从定义开始", "typst_version": "0.15.1", "metadata": {}
  },
  "chapters": [{
    "slug": "chapter-1", "tag": "1", "title": "极限", "summary": "",
    "sections": [{
      "slug": "section-1", "tag": "1.1", "title": "数列极限", "summary": "",
      "source": "先阅读定义。\n#mm-knowledge(slug: \"sequence-limit\")"
    }]
  }]
}
```

summary在API保存体中对应revision.descr。文件包含讲义slug、标题、副标题、简介、排版版本、metadata、章/节文案和完整小节source；**不包含**数据库行ID、occurrence_id、所有者、协作者、会话、历史版本、审核记录、发布/推荐状态、批注或掌握记录。引用只保留宏字符串，不内嵌知识点正文；离线文件不保证可脱网展开引用。

lecture.slug非空、最长100且符合小写字母/数字/连字符规则；title最长200、subtitle最长500、summary最长5000，typst_version非空最长50。章/节slug非空最长100，章内小节slug不得重复，整份章slug不得重复；tag/title/summary最长5000。每节source最长200000字符，可空。最多100章、每章200节、全份2000节。**在线导入还受加密封装后4 MiB请求体限制**；这些数量上限不能相乘后当作可接受文件大小。

## 整本导入与导出

工作台左侧“本地讲义”或有权创建的在线分组提供JSON导入。读取格式后可改讲义slug，确认后创建新讲义，不覆盖旧记录。本地slug在本浏览器内唯一；在线slug在后端库内唯一，冲突须改名。

| 场景 | 实际行为 |
| --- | --- |
| 在线导入 | POST `/api/lectures/import`，Body直接是完整JSON，经现有通信加密；所有者取登录账号；201返回lecture和首个draft revision |
| 本地导入 | 在当前浏览器新建本地记录，不上传；生成新本地UUID及章/节occurrence_id |
| 在线导出 | GET `/api/lecture-revisions/{id}/export`，导出当前选中版本；公开读者仅能导出当前已发布approved版本，有私有查看权限者可导出其可读版本；归档讲义禁止导出 |
| 本地导出 | 从已保存的本地记录转换为相同JSON；旧blocks/动画等不兼容内容会拒绝导出 |

导出前应先保存；前端有未保存修改时阻止导出，不会悄悄导出内存未保存输入。导入没有幂等键，超时或响应不完整时先刷新列表核对，避免重复创建。

metadata按原对象保留，可携带封面等渲染配置。前端导出时递归拒绝部分身份/凭据字段名，但这不是完整内容脱敏；后端仅检查metadata为对象，不保证扫描正文或任意键名。不要把凭据写进source或metadata。

## 章节内批量导入小节

在**可编辑章节**选择一个或多个 `.typ` 文件。按选择顺序逐个以严格UTF-8读取，一个文件追加为一个小节；文件名去扩展名作为标题，并推导初始slug。中文名等可能推导出空slug，确认窗口中必须补齐。标题、slug均不能为空，slug不能与当前章已有或本次其他小节重复。

确认只将这些小节加入当前内存树，须再“保存讲义”才持久化。它不是整本JSON导入，不识别JSON章节结构，也不自动按Typst标题拆分多个小节。不支持在这个批量入口导入PDF、Markdown或任意文本扩展名。切换章节会丢弃待确认的文件选择，需重新选择。

当前小节编辑面板没有独立的源码文件替换入口；如需替换已有小节内容，在源码编辑器中修改并保存。讲义归档或只读快照不能编辑、导入小节。

文件不携带数据库中的讲义分类ID，导入后需重新选择讲义分类；导入的新在线或本地章/节生成新的occurrence_id。
