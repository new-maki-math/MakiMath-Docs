# 导入与导出

整本讲义用 JSON 交换，小节批量导入使用 `.typ`。两者入口和结果不同：JSON 新建一份讲义；`.typ` 追加到选中的章节，不替换整本内容。

## 整本讲义 JSON

在工作台选择讲义及版本，先保存修改，再“导出 JSON”。文件只有这个版本的标题、目录、正文、渲染配置和封面，不包含所有者、协作者、审核记录、历史版本、发布状态或掌握记录。引用只保留源码中的 slug 宏，不把公共知识点正文打包进去，因此不能承诺脱网后引用仍可展开。

在本地或在线分组选择导入，读取文件后核对 slug，再确认。导入总是新建，不覆盖已有讲义；slug 冲突时改名。在线导入得到未发布的工作草稿，分类需要重新选择，章/节生成新的实例标识。结果不确定时先刷新列表核对，避免重复创建。

文件格式如下，字段均必填，空文案也要保留空串。下面是一份最小示例。

```json
{
  "type": "maki-lecture",
  "schema_version": 1,
  "lecture": {
    "slug": "limits", "title": "极限入门", "subtitle": "",
    "summary": "从定义开始", "typst_version": "0.15.1", "metadata": {}
  },
  "chapters": [{
    "slug": "chapter-1", "tag": "1", "title": "极限", "summary": "",
    "sections": [{
      "slug": "section-1", "tag": "1.1", "title": "数列极限", "summary": "",
      "source": "#mm-knowledge(slug: \"sequence-limit\")"
    }]
  }]
}
```

文件里的 lecture.summary 对应在线草稿的 descr。metadata 可包含封面 Data URL；在线导入会提取并检查封面，限制为 512 KiB。本地允许的 5 MiB 封面不保证能直接导入线上，应先缩小。导出没有扫描正文中的凭据，metadata 的字段名检查也不是完整脱敏器，别把账号密钥写进文件。

| 限制 | 值 |
| --- | --- |
| 讲义 slug / 标题 / 副标题 / 简介 | 最长 100 / 200 / 500 / 5000 字符 |
| 章、节 slug | 非空、最长 100；章 slug 在讲义内唯一，节 slug 在章内唯一 |
| 章、节 tag/title/summary | 最长 5000 字符 |
| 每节源码 | 最长 200000 字符 |
| 章节与小节数量 | 最多 100 章，每章 200 节，总计 2000 节 |
| 在线请求体 | 加密封装后的整个请求最多 4 MiB，封面也占大小 |

数量上限不代表所有源码都写满时仍能导入。未知字段、旧 blocks/动画结构和不支持的 schema_version 会被拒绝。

## 章节内导入多个小节

在可编辑章节里选一个或多个 `.typ` 文件，按严格 UTF-8 读取。一个文件成为一个新小节，文件名先作为标题并推导 slug；中文文件名可能推导出空 slug，确认前要补全。slug 不能与章内已有或同批文件重复。

确认只追加到当前编辑内容，之后还要保存讲义。此入口不支持 PDF、Markdown 或任意扩展名，也不会按文件中的标题自动拆节。切换章节会取消待确认选择。替换已有小节时，直接改其源码；当前没有独立的源码文件替换入口。
