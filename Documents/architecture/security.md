# 通信、认证与权限边界

依据后端ea63e51。通信封装使用P-256 ECDH协商和AES-256-GCM，协议见[接口约定](../api/overview.md)。这不能替代HTTPS或服务端授权，也不能阻止已获授权的客户端读取内容。禁止使用“无法复制”“完全安全”等承诺。

登录使用Bearer访问令牌，服务端查询有效账号和会话记录。刷新令牌在数据库仅存哈希，每次刷新轮换；注销按提供的刷新令牌删除匹配会话，改密和停用账号删除其全部会话。注销不匹配仍返回204，详见[认证 API](../api/auth.md)。

后端区分知识点管理权限、讲义所有者、view/edit协作者和super_admin。客户端按钮显隐不构成授权。提交后的版本不能原地修改；审核与公开指针更新在同一事务执行。

当前接口不接受旧动画字段，后端不执行Typst源码，也不检查源码中每个引用目标。前端只映射支持的语法，不能把任意宏或文本作为脚本执行。讲义归档阻断常规修改，管理员可通过受限接口永久删除已归档讲义；三步确认由前端完成，不替代后端管理员及归档状态校验。

服务端自定义私钥须与固定公钥匹配。管理员自审当前仍允许，是否增加规则需另行确认。完整JSON导出不含身份/会话顶层字段，但任意metadata和正文不是自动脱敏器，不能在其中保存凭据。
