# 通信、认证与权限边界

依据后端main df87ca0。通信封装使用P-256 ECDH协商和AES-256-GCM，协议见[接口约定](../api/overview.md)。这不能替代HTTPS或服务端授权，也不能阻止已获授权的客户端读取内容。禁止使用“无法复制”“完全安全”等承诺。

登录使用Bearer访问令牌，服务端查询有效账号和会话记录。刷新令牌在数据库仅存哈希，每次刷新轮换；注销按提供的刷新令牌删除匹配会话，改密和停用账号删除其全部会话。注销不匹配仍返回204，详见[认证 API](../api/auth.md)。

后端区分知识点版本贡献者、讲义所有者、view/edit协作者和super_admin。客户端按钮显隐不构成授权。提交后的版本不能原地修改；审核与公开指针更新在同一事务执行。

animation递归拒绝scenes_code及同名变体。其他动画字段只有对象及禁用键检查，并不代表任意内容经过业务审核或可安全执行。旧动画执行方式需另行适配。服务端自定义私钥与固定公钥的对应问题、自审和停用内容引用边界列于[核对记录](../api/verification.md)。
