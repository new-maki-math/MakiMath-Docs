# 前端架构 (Vue 3 + WASM)

MakiMath 前端单页应用（代码位于 `maki-math-frontend` / `maki-math-re`）基于 Vue 3.5 与 Vite 8 构建。前端摆脱了笨重第三方 UI 库的包袱，采用全自研轻量级组件系统与 WebAssembly 矢量排版引擎，实现了极致的交互性能与高保真数学排版。

## 前端技术选型

![前端技术架构与模块划分](/images/arch-frontend.svg)

- **核心框架**：Vue 3.5（全面采用 `<script setup>` 与 Composition API）+ Vite 8 构建管道。
- **排版引擎**：基于 `typlet` 的 WebAssembly 运行时，直接在浏览器端解析并绘制矢量级 Typst 文档。
- **图谱引擎**：`d3`（v7），用于课程前置依赖的有向无环图力导向与层级排版推导。
- **设计与主题系统**：自研轻量 CSS 主题系统（`style-light.css` / `style-dark.css`），原生支持深浅色无缝自适应切换。
- **字体资产**：集成 `@fontsource/noto-sans-sc`，保证跨操作系统（Windows / macOS / Linux）中文与数学符号的高品质统一渲染。

## 核心系统设计

### 1. 讲义矢量渲染引擎 (`TypstDoc.vue`)
前端通过 `TypstDoc.vue` 封装底层 `typlet` WASM 编译实例：
- **编译流程**：组件接收后端返回的纯文本 Typst 源码，注入预设样式与全局宏模板后送入 WASM 线程。
- **矢量直出**：编译输出高保真 SVG/HTML 节点直接挂载于 DOM。
- **公式无限缩放**：数学符号与定理版面基于矢量矢量路径渲染，彻底消除传统位图公式放大后的模糊锯齿现象。
- **暗黑主题自适应**：监听系统主题变化，动态注入 CSS 变量，确保数学公式与背景色对比度始终处于护眼水准。

### 2. 编者三栏协同工作台 (`views/workbench/`)
工作台是内容编纂的核心阵地，由三大协同模块构成：
- **左侧：目录树导航区 (`WorkbenchTree`)**
  - 支持拖拽调序，鼠标释放后异步调用 `/api/sections/reorder` 更新后端 `pos` 权重。
  - 右键上下文菜单提供快速创建、重命名、依赖关系设置与小节归档。
- **中间：源码编辑区 (`MCodeEditor.vue`)**
  - 集成数学公式常用宏一键插入（定理块、定义卡片、极限矩阵等）。
  - 支持撤销/重做栈与热键绑定（`Ctrl + S` 保存，`Ctrl + Z` 回退）。
  - 脏数据守卫（Dirty State）：在未保存离开页面时弹出拦截确认提示。
- **右侧：WASM 实时预览区 (`TypstDoc.vue`)**
  - 编者输入字符后通过 300ms 防抖自动触发增量编译，即时呈现矢量排版成品。

### 3. D3 拓扑路线图计算 (`RoadmapGraph.vue`)
- **前置网络建模**：从课程元数据中提取章节与小节依赖，在客户端构建 DAG 有向图节点与连线集合。
- **交互与高亮**：
  - 点击节点高亮其“直接前置依赖路径”与“后续解锁路径”。
  - 支持画布置中、平移与滚轮缩放，为学习者提供清晰的学习导航。

## 通信与安全处理

前端在 `src/api/` 中集成了统一的通信拦截机制：
1. **自动会话维护**：应用在网络层自动维护会话状态与通信上下文。
2. **请求统一封装**：数据在离开浏览器网络栈前由通信层自动封装与保护，避免明文直接交互。
3. **响应透明解析**：API 拦截器统一解析服务端返回载荷，交付给业务视图组件的是纯净的标准数据。
