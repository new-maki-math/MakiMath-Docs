如果你是**数学教师、助教、内容创作者或讲义编纂者**，本篇指南将帮助你了解如何入驻 MakiMath 平台并开始创作你的第一门结构化数学讲义。

## 编者（Editor）在平台中的角色

在 MakiMath 中，讲义内容与学习网络由编者共同打造：
- **免繁琐配置**：无需在本地搭建任何 Node.js、数据库或复杂的 LaTeX 编译器，直接在浏览器端工作台完成所有编排与排版。
- **结构化思维**：以“知识图谱”的视角组织课程，不仅写内容，更能定义小节之间的**前置学习依赖（Prerequisites）**。
- **实时所见即所得**：依托现代 Typst 与 WASM 引擎，浏览器端秒级渲染高保真数学矢量公式。

## 第一步：获取邀请码与注册入驻

为了保障学术讲义的高质量与版权合规，MakiMath 编者采取**邀请码准入制**。

1. **获取邀请码**：联系平台超级管理员获取专属注册邀请码（格式如 `MK-A8B9C2`）。
2. **注册编者账号**：
   - 打开平台首页，访问或点击右上角用户入口。
   - 在弹出的注册模态框中，填写：
     - 用户名（英文/数字）
     - 显示名称（如：张三老师）
     - 密码
     - 邀请码
   - 点击提交完成注册并自动登录。

## 第二步：熟悉讲义层级体系

在动手编写之前，请先建立平台的四级层级心智：

![讲义四级层级模型](/images/editor-hierarchy.svg)

> [!TIP]
> - **分类** 与 **课程大纲** 由管理员或课程负责人初始化。
> - **章节** 与 **小节** 是编者的主要创作阵地。小节是真正承载 Typst 讲义内容与公式的核心单元。

## 第三步：进入讲义工作台 (`/workbench`)

登录编者账号后，访问顶部或菜单中的 **讲义工作台**（`/workbench`）：

### 1. 工作台布局概览
- **左侧树状目录**：展示你有权限编辑的课程目录树。可在此新增章节、新增小节、拖拽调整显示顺序。
- **中间内容编辑区**：Typst 源码编辑器，支持实时语法高亮、快捷插入公式、撤销重做。
- **右侧/预览区**：基于 Typlet WASM 的真实讲义渲染视图，毫秒级响应你的每一次键入。

## 第四步：编写你的第一篇数学讲义

点击工作台中的某个小节，在编辑区即可开始用 **Typst** 编写讲义正文：

```typst
#let theorem(title, body) = block(
  fill: rgb("f8fafc"),
  inset: 12pt,
  radius: 6pt,
  stroke: (left: 4pt + rgb("0284c7")),
)[
  *定理* (#title) \
  #body
]

== 等价无穷小代换定理

#theorem("基本代换原则")[
  设在自变量同一变化过程中，$alpha ~ alpha'$ 且 $beta ~ beta'$，且 $lim (alpha')/(beta')$ 存在，则：
  $ lim (alpha)/(beta) = lim (alpha')/(beta') $
]

*核心注意点*：
1. 乘除项可**直接整体代换**；
2. 加减项代换需格外小心，必须满足差项主部不被完全抵消的充分条件。
```

> [!NOTE] 为什么是 Typst？
> 相比传统 LaTeX，Typst 的公式语法极其直观自然：
> - 行内公式直接用 `$x + y$` 包裹。
> - 独行公式用 `$ \sum_{i=1}^n x_i = C $`。
> - 分数写法 `$a/b$` 告别冗长的 `\frac{a}{b}`。
> 详见 [Typst 数学排版指南](../authoring/typst-guide.md)。

## 第五步：编排前置依赖（知识图谱）

在小节属性面板中，找到 **前置依赖设置 (Prerequisites)**：

1. 打开 **前置依赖选择器**。
2. 勾选学习本小节前学员“必须掌握”的前置小节。
   - *例如：学习“洛必达法则求极限”前，勾选“导数与微分的基本运算”和“柯西中值定理”。*
3. 点击保存。系统会自动检测是否构成循环依赖（平台杜绝循环引用环）。
4. **效果**：前台知识图谱页面会自动绘制依赖箭头，并在读者端该小节提示：*“学完柯西中值定理后可学”*。

## 第六步：保存与发布状态

课程和小节具备以下状态流转：

| 状态 | 说明 |
|---|---|
| **`draft` (草稿)** | 仅编者与管理员可见，用于创作中的排版打磨。 |
| **`live` (已发布)** | 面向全网免登读者完全公开。 |
| **`hidden` (隐藏)** | 暂时下架维护，已有直接链接可预览。 |
| **`archived` (归档)** | 历史沉淀版本，只读存档。 |

在小节编辑完成后，点击 **保存并生效**，你的讲义即刻在知识图谱和阅读器中呈现给广大学习者！
