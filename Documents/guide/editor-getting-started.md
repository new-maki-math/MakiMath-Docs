# 编者入门

不登录也可在讲义工作台创建、导入和编辑本地讲义。它们保存在当前浏览器，不自动同步到账号或其他设备。

编写在线讲义先向管理员获取邀请码，通过注册创建账号，再单独登录。在线创建后得到工作草稿，逐章逐节填写标题、slug和完整Typst源码。公共知识点由管理员直接维护，普通编者不能在讲义里改写它；引用使用`#mm-knowledge(slug: "sequence-limit")`。阅读引用会取当前有效正文，不是固定知识点版本。

先保存再提交，提交得到独立审核快照，工作草稿可以继续改。一个讲义只能有一个待审核快照。管理员审核通过后发布，推荐另行管理。审核完成回到工作台时核对草稿更新提示，不要丢弃尚未保存的输入。

归档在线讲义是整本操作，恢复后不会自动公开；管理员可另行永久删除已归档讲义。详细范围见[工作台](../authoring/workbench.md)。源码仅支持[已适配的Typst和MM宏](../authoring/typst-guide.md)，不是完整Typst项目导入。
