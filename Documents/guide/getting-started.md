# 快速上手指引

欢迎来到 MakiMath 文档中心！为了帮助你最快找到所需的信息，请选择你的目标角色：

::: tip 🛠️ 我是开发者
如果你想在本地搭建全栈环境、参与前后端开发、贡献代码或了解架构底层细节：
- 包含 Node.js、PostgreSQL 数据库搭建、前后端联动启动与调试说明。
- 👉 **前往阅读：[开发者全栈快速上手](./dev-getting-started.md)**
:::

::: tip ✍️ 我是编者 / 创作者
如果你是数学教师、讲义创作者，想要直接在平台编写数学讲义、编排知识图谱依赖：
- 无需搭建本地编程环境，在浏览器即可完成所有讲义创作。
- 👉 **前往阅读：[编者入驻与快速上手](./editor-getting-started.md)**
:::
