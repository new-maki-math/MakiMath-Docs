# 管理员操作

超级管理员负责账号准入、公共知识库和讲义审核。编者可以维护有编辑权限的讲义，不能创建或修改公共知识点。首次管理员由部署人员在后端终端创建，见[部署](../deploy/self-host.md)。

## 发邀请码与管理账号

登录平台管理页，创建邀请码，选择角色、次数和可选有效期。注册者获得的是邀请码指定的角色；注册后需单独登录。撤销邀请码只阻止后续使用，不等于停用已经注册的账号。

停用账号会撤销其全部会话，当前管理员不能停用自己。修改个人密码同样会使所有会话失效，需要重新登录。操作审计记录用于查阅请求，不是内容版本备份，也不能拿来恢复已删除讲义。

## 维护知识点

在知识点工作台新建分类和知识点。每点填写固定 slug、标题和正文，直接保存后对公开阅读生效，没有知识点审核或版本回滚。多人同时改同一点时以最后一次成功写入为准，当前没有 edit_version 冲突保护。

正文采用一个完整 MM 内容框，例如 `#mm-box-definition[定义正文]`。标题字段会显示在首个顶层框的标题位置，引用中的掌握按钮也挂在首框上。单框是编写约定，保存接口没有校验恰好一个框；多框或没有顶层框不会自动被整理。

分类可多选，前置关系独立维护。管理接口返回的分类关联可能包括已归档分类，不应因为公开分类列表看不到它就直接清空关联。分类和前置关系整组保存，数据库拒绝成环。

归档使知识点从公开接口消失，已有讲义引用显示缺失占位；恢复为 active 后可再次读取。永久删除会清理该点的分类和入/出前置关系，不改写讲义源码，也不清理浏览器记录。删除分类会删除整棵子树及只属于该范围的知识点；还关联范围外分类的点保留。不要复用已经被讲义引用的 slug。

知识分类的 JSON 导入入口只对有效一级分类提供。文件中的顶层分类挂到目标分类下，未直接指定分类的点归入目标。它只新增，不覆盖同 slug 内容；[知识点 API](../api/knowledge.md)列出格式与限制。

## 审核和整理在线讲义

平台审核列表显示待审核快照，并可进入相应版本阅读。核对目录、源码、封面和引用后，再通过或驳回。通过会发布快照，同时更新来源草稿的并发号 edit_version；驳回不改变已有公开版本。当前允许管理员审核自己提交的快照。

审核固定的是讲义源码，引用的公共正文仍会动态变化。归档讲义不能审核，先恢复才可继续处理。推荐标记另外设置：首次通过不会自动推荐，已推荐讲义新版通过也不会自动取消推荐。

工作台“全部在线讲义”提供管理员管理摘要，列出所有者、状态和最新版本信息。摘要不是自动加载整本正文，进入编辑或阅读后再获取目录和小节。管理员可归档、恢复及永久删除已归档讲义，具体范围见[讲义维护](../authoring/workbench.md#归档与恢复)。
