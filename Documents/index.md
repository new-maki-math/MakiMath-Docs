# MakiMath 使用文档

想找讲义阅读，先看[阅读与我的书架](./guide/reading.md)。想自己编写，直接从[创建第一份讲义](./authoring/workbench.md)开始；不登录也能编辑本地讲义。

| 你要做什么 | 看这里 |
| --- | --- |
| 找知识点、查看前置关系、记录掌握情况 | [阅读与我的书架](./guide/reading.md) |
| 写正文、插入公式、引用知识点 | [Typst 与 MM 宏](./authoring/typst-guide.md) |
| 从文件导入、导出备份、批量添加小节 | [导入与导出](./authoring/import-export.md) |
| 维护知识库、审核讲义、归档或删除 | [管理员操作](./guide/admin.md) |
| 在本机开发 | [本地开发](./guide/development.md) |
| 部署网站或更新已有数据库 | [部署与升级](./deploy/self-host.md) |
| 对接接口 | [API 约定](./api/overview.md) |
